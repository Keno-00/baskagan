# Contributing

Thanks for helping improve Baskagan SDE. Small, focused changes are easiest to review.

## Before you start

- For a substantial behavior or interface change, open an issue first so the direction can be discussed.
- Follow the repository instructions in `AGENTS.md`.
- Avoid including private project files, credentials, or personal paths in issues, logs, or screenshots.

## Local setup

Install Rust, Node.js, and the Windows build prerequisites described in the [development guide](docs/DEVELOPMENT.md). The checked-in editor and terminal assets let you run the app without rebuilding the JavaScript bundle.

## Before opening a pull request

Run the relevant checks from the [development guide](docs/DEVELOPMENT.md). For app or UI changes, include a screenshot or short recording that shows the result. Update the user or development guide when behavior or setup changes.

The pull request template includes a compact checklist for context, verification, and visuals.
