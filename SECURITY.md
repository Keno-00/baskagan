# Security policy

Please do not report vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting page](https://github.com/Keno-00/baskagan/security/advisories/new) to share a report privately. If private reporting is unavailable, contact the repository maintainer through GitHub and request a private channel before sharing technical details.

Please include the affected version or commit, the impact, and steps to reproduce when safe to share. Give maintainers a reasonable opportunity to investigate before public disclosure.
